## 三、自然语言自动触发与分级读取

不依赖斜杠命令触发。满足以下任意一组信号时，自动进入项目研发工作流：

1. 当前工作区位于已初始化项目根目录或其子目录下。
2. 用户提到项目模块、类名、接口、页面、文件路径、业务名词。
3. 用户表达研发意图，例如优化、改造、实现、分析原因、给方案、接口、字段、校验、按钮、样式、报错、异常、评审。
4. 对话已建立项目上下文，用户用短句反馈，如"间距需要优化""没有对齐""代码有问题"，应继承当前项目和任务上下文。

### 1. 分级读取表

触发后按任务风险等级读取记忆，不得默认全量读取：

| 任务级别 | 读取要求 |
| --- | --- |
| 低风险微调（纯样式、文案、间距、对齐等） | 继承当前会话上下文直接执行；本会话尚未读取任何记忆时，只读 `project-config.json`。 |
| 中风险任务（单模块功能、页面行为、接口调用等） | 在已有上下文基础上，本会话未读过则补读 `module-map.md` 相关模块段落；涉及代码修改再补读 `static-memory.md`。 |
| 高风险任务（业务规则、表结构、接口契约、权限、状态流转、跨模块联动） | 在中风险读取基础上，本会话未读过则补读 `business-memory.md`。 |

### 2. 读取去重规则

1. 同一记忆文件同一会话只读一次；内容已在上下文中的不得重复读取。
2. 记忆文件被修改后，只需重读被修改的文件或段落。
3. 短句反馈继承当前任务上下文，不重新触发读取链。
4. 其他章节涉及记忆读取时均引用本章规则，不另行定义读取范围。

### 3. 负向触发规则

纯咨询、解释、概念问答等不修改项目产物的对话，AI 直接回答，不触发分级读取链、不进入研发工作流、不沉淀记忆；即使当前工作区位于已初始化项目内也不例外。只有用户表达修改、实现、排查、设计等研发意图时，才进入工作流。
