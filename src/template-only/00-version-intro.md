V2.2.1 基于 V2.2.0 迭代，主题为吸收 Spec Kit 的阶段产物与规格收敛思想。

相对 V2.2.0 的变更：

1. 新增：Spec-backed Development Mode，用于中高风险任务生成轻量 `spec.md → plan.md → tasks.md` 并推进实现。
2. 新增：`.codex-project/specs/<日期-主题>/` 阶段产物目录，用于保存单次功能的规格、计划、任务、验证和收敛证据。
3. 增强：完成前验证加入 convergence 检查，逐项核对规格、计划、任务、实现和验证证据是否一致。
4. 收紧：阶段产物与长期记忆分流，只有已确认、已验证且可复用的事实才沉淀到 `memory/`。
